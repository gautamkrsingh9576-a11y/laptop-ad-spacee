Fullscreen video hero, floating navigation, asymmetric campaign gallery,

LAPTOP AD SPACE — HTML / CSS / JAVASCRIPT

GET STARTED
1. Extract the complete ZIP.
2. Open index.html in a browser.
3. Keep assets next to index.html, style.css and script.js.
4. Upload these files together to a static website host when ready.

FILES
index.html: all page content and Google Form enquiry links.
style.css: responsive layout, lime-green palette and typography.
script.js: placement selector, video pause/play and sharing.
assets/: supplied campaign images, laptop photo, hero video and poster.

VIDEO
The supplied 10-second MP4 autoplays muted and loops inline.
Autoplay is subject to browser/device policy. A pause/play button is available.
Reduced-motion preferences stop autoplay. Poster remains visible before playback.
Replace assets/hero.mp4 to change the video; replace hero-poster.jpg to update its fallback.

ENQUIRY
All five enquiry links open the supplied Google Form in a new tab.
The website does not submit data directly to a spreadsheet. To store form responses
in Sheets, manage that connection in Google Forms. Form permissions and submissions
were not tested; the destination URL is exactly the one supplied.

VALIDATION
JavaScript syntax, local asset paths, anchor targets and enquiry links checked.
No browser visual or end-to-end form test performed.

IMAGERY
Campaign images and video are illustrative. Brand logos do not imply sponsorship.
